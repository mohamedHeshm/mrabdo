# 🎓 EduSystem - نظام إدارة التعليم

منصة تعليمية متكاملة تدعم 3 أنواع مستخدمين: **المدير، المدرس، الطالب**.

---

## 🚀 تشغيل المشروع محلياً

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل السيرفر
npm run dev

# 3. افتح المتصفح على
http://localhost:5173
```

---

## ✨ المميزات

### 👑 المدير
- إضافة / حذف المدرسين والطلاب
- إيقاف الحسابات مؤقتاً أو تفعيلها
- عرض سجل نشاط جميع المستخدمين
- عرض بروفايل أي مستخدم

### 👨‍🏫 المدرس
- نشر الواجبات مع وصف وتاريخ التسليم
- استعراض تسليمات الطلاب وتصحيحها وإضافة الدرجات
- إضافة ملاحظات خاصة لكل طالب (تظهر للطالب)
- رفع فيديوهات يوتيوب (شرح / ملخصات)
- صفحة بروفايل شخصية مع صورة ونبذة

### 🎓 الطالب
- مشاهدة الواجبات وتحميلها وتسليمها
- مشاهدة الدرجات وملاحظات التصحيح
- قراءة الملاحظات الخاصة به من المدرس
- مشاهدة الفيديوهات التعليمية
- صفحة بروفايل شخصية مع صورة ونبذة
- عرض بروفايلات الطلاب الآخرين
